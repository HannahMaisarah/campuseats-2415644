# CampusEats – Campus Food Ordering System

## 1. Project Overview

CampusEats is a web-based campus food ordering application developed using React. It allows students to explore available food vendors, browse menus, customise food and drink preferences, add items to their shopping cart, place orders, and view their order history.

The application aims to provide a convenient and user-friendly food ordering experience for students within the campus environment.

## 2. Main Features

- **Vendor Listing:** Browse available food vendors and their information.
- **Vendor Menu:** View food items, descriptions, prices, categories, and availability.
- **Shopping Cart:** Add, remove, and update food item quantities.
- **Checkout:** Place orders through a checkout form with input validation.
- **Order History:** View previously placed orders.
- **Food Customisation:** Select preferred spice levels for eligible food items (Not Spicy, Mild, Medium, and Hot).
- **Drink Customisation:** Choose between Hot and Iced options for drinks.
- **Separate Cart Items:** Different customisation options for the same menu item are stored as separate cart lines.
- **Data Persistence:** Store cart and order information using browser localStorage.
- **Page Navigation:** Navigate between the home page, vendor menu, shopping cart, and order history.

## 3. Technologies Used

- React
- JavaScript
- React Router
- Vite
- HTML and CSS
- Browser localStorage

## 4. Installation and Setup

To run CampusEats locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/HannahMaisarah/campuseats-2415644.git
   ```

2. Navigate into the project directory:

   ```bash
   cd campuseats-2415644
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

To check the code using ESLint:

```bash
npm run lint
```

To create a production build:

```bash
npm run build
```
